# 📡 برنامج محاسبة الإنترنت

موقع ويب لإدارة مشتركي الإنترنت: المشتركين، المحفظة، التفعيل والترحيل، الباقات، والتقارير.
كل البيانات تنحفظ بملف واحد `internet_accounting.db` (قاعدة بيانات SQLite).

## المميزات
- **لوحة تحكم**: الرصيد، عدد المشتركين، أرباح الشهر، والاشتراكات المنتهية أو القريبة من الانتهاء.
- **المشتركون**: إضافة، تعديل، حذف، بحث، فلترة حسب الحالة أو الباقة، وسجل عمليات لكل مشترك.
- **التفعيل والترحيل**: يخصم سعر الجملة من المحفظة ويحسب تاريخ الانتهاء (30 يوماً). الترحيل يضيف المدة على الاشتراك الفعّال، ويمكن تغيير الباقة أثناء العملية.
- **المحفظة**: شحن وخصم يدوي مع سجل الحركات.
- **الباقات والأسعار**: إضافة الباقات وتعديلها وحذفها. الربح يُحسب تلقائياً، والعمليات القديمة تحتفظ بأسعارها.
- **التقارير**: فلترة حسب التاريخ، الأرباح حسب الباقة، تصدير Excel، وطباعة.
- **الإعدادات**: تغيير كلمة المرور، إضافة مستخدمين، وتحميل نسخة احتياطية من قاعدة البيانات.

## التشغيل على الحاسبة
```bash
pip install -r requirements.txt
python app.py
```
بعدها افتح المتصفح على: http://localhost:5000

الدخول الأول: `admin` / `admin123`. **غيّر كلمة المرور فوراً من صفحة الإعدادات.**

## التشغيل على سيرفر (موقع على الإنترنت)
```bash
export SECRET_KEY="اكتب-هنا-نص-عشوائي-طويل"
gunicorn -w 1 -b 0.0.0.0:8000 app:app
```
متغيرات اختيارية:
- `DB_PATH` لتحديد مكان ملف قاعدة البيانات.
- `PORT` لتحديد المنفذ عند التشغيل بـ `python app.py`.

> ملاحظة: على مواقع مثل Render أو Railway لازم تربط **قرص دائم (Persistent Disk)** وتوجّه `DB_PATH` عليه، وإلا تنمسح البيانات عند كل إعادة تشغيل.
